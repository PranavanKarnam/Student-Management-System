# Student Management System

## PPS Individual Mini Project

**Language:** C Programming

**Developed by:** K Sai Pranavan

## Project Description
The Student Management System is a simple C-based application used to manage student details and academic marks.

## Features
- Add student details
- Display student records
- Search students using roll number
- Calculate total marks
- Calculate percentage
- Generate grades

## Technologies Used
- C Programming
- OnlineGDB
- GitHub
