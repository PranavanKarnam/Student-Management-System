# STUDENT MANAGEMENT SYSTEM

## PPS Individual Mini Project

**Programming Language:** C

**Project Type:** Individual Project

**Project Developer:** K Sai Pranavan

---

## 1. INTRODUCTION

The Student Management System is a simple application developed using the C programming language.

It is designed to store and manage student information, including roll numbers, names, subject marks, total marks, percentages and grades.

The project demonstrates the practical implementation of basic programming concepts.

## 2. OBJECTIVES

- To store student details.
- To display student records.
- To search students using roll numbers.
- To calculate total marks.
- To calculate percentages.
- To generate grades automatically.

## 3. SOFTWARE REQUIREMENTS

- Programming Language: C
- Compiler: GCC
- Online Platform: OnlineGDB
- Code Repository: GitHub

## 4. CONCEPTS USED

1. Variables and Data Types
2. Structures
3. Arrays
4. Functions
5. For Loops
6. Do-While Loop
7. If-Else Statements
8. Switch Statements
9. Input and Output Functions

## 5. FEATURES

### Add Student
Allows the user to enter student roll number, name and marks in three subjects.

### Display Students
Displays all stored student records.

### Search Student
Searches for a student using their roll number.

### Calculate Percentage
Calculates total marks and percentage automatically.

### Grade Calculation
Assigns grades according to the percentage.

- 90 and above: A
- 80 to below 90: B
- 70 to below 80: C
- 60 to below 70: D
- Below 60: F

## 6. ALGORITHM

1. Start the program.
2. Display the main menu.
3. Ask the user to select an option.
4. Add student details when option 1 is selected.
5. Display all records when option 2 is selected.
6. Search for a student when option 3 is selected.
7. Exit when option 4 is selected.
8. Repeat the menu until the user exits.
9. Stop the program.

## 7. EXPECTED OUTPUT

The program successfully adds student details, displays records, searches using roll numbers and calculates total marks, percentages and grades.

## 8. ADVANTAGES

- Simple and user-friendly.
- Reduces manual calculations.
- Provides quick searching.
- Organizes student information.
- Demonstrates fundamental C programming concepts.

## 9. LIMITATIONS

- Supports a maximum of 100 students.
- Records are stored temporarily in memory.
- Records are lost when the program terminates.
- Each student has marks for only three subjects.
